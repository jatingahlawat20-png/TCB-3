# 📖 Overview

TCB-3 (Trainer Client Bridge) is a production-oriented full-stack web platform designed to bridge the gap between professional fitness trainers and clients.

The platform allows trainers to showcase their expertise, coaching packages, transformations, and achievements while enabling clients to discover trainers, compare profiles, communicate securely, and purchase coaching programs.

Unlike simple portfolio projects, TCB-3 is being developed as a real-world scalable application following modern full-stack architecture.

# ⚡ Installation

Clone the repository

```bash
git clone https://github.com/jatingahlawat20-png/TCB-3.git
```

Go inside the project

```bash
cd TCB-3
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
